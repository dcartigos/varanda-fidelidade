1. Quem somos

O Varanda Restaurante é um restaurante localizado em Paranavaí, Paraná, operado por FOODS LC LIMITADA (CNPJ 58.454.056/0001-04). Esta política descreve como tratamos os dados pessoais dos nossos clientes no âmbito do nosso programa de fidelidade e da comunicação por WhatsApp.

Esta política é elaborada em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018).

2. Quais dados coletamos

Coletamos apenas o mínimo necessário para operar o programa de fidelidade:

  • Nome — informado pelo cliente no momento do cadastro no caixa do restaurante
  • Número de telefone / WhatsApp — informado pelo cliente no cadastro
  • Saldo de pontos do programa de fidelidade — gerado pelo nosso sistema de caixa a partir das compras
  • Histórico de visitas e de resgates de pontos
  • Registro das mensagens enviadas — data, hora, conteúdo e status de entrega
  • Preferências de comunicação — se o cliente autorizou receber avisos de pontos e/ou mensagens promocionais

Não coletamos: CPF, endereço residencial, dados bancários, dados de cartão de crédito, dados de saúde, dados biométricos, geolocalização ou qualquer dado pessoal sensível.

3. Como coletamos

Os dados são fornecidos voluntariamente pelo próprio cliente, no balcão do restaurante, ao se cadastrar no programa de fidelidade. Não compramos listas de contatos, não coletamos dados de terceiros e não capturamos dados de forma automatizada sem o conhecimento do cliente.

4. Para que usamos os dados

  • Informar o saldo de pontos do programa de fidelidade após uma visita ao restaurante
  • Avisar quando o cliente já pode resgatar um benefício acumulado
  • Enviar comunicações promocionais (cardápio do dia, promoções, eventos) — somente para quem autorizou expressamente esse tipo de mensagem
  • Atender o cliente quando ele nos escreve pelo WhatsApp
  • Gerar relatórios internos de gestão, sempre de forma agregada

Não usamos os dados para nenhuma outra finalidade sem obter novo consentimento.

5. Base legal

  • Consentimento (art. 7º, I da LGPD) — para o envio de mensagens promocionais e de marketing
  • Execução de contrato / legítimo interesse (art. 7º, V e IX) — para a operação do programa de fidelidade e o envio de informações transacionais sobre o saldo de pontos do próprio cliente

6. Consentimento e como cancelar

Tratamos separadamente dois tipos de autorização:

  • Mensagens de pontos (transacionais, sobre o saldo do próprio cliente)
  • Mensagens promocionais (marketing, ofertas e novidades)

Para cancelar a qualquer momento

Basta responder SAIR em qualquer mensagem que enviarmos pelo WhatsApp. O bloqueio das mensagens promocionais é aplicado imediatamente. Também é possível pedir o cancelamento pessoalmente no caixa do restaurante ou pelos contatos no fim desta página.

7. Regras que aplicamos aos envios

Por respeito ao cliente, nós mesmos nos impomos os seguintes limites:

  • Nenhuma mensagem é enviada após as 18h
  • Nenhuma mensagem é enviada no domingo
  • No máximo 1 a 2 mensagens promocionais por semana por cliente
  • Nenhuma mensagem duplicada para o mesmo cliente no mesmo dia
  • Toda comunicação identifica claramente que é do Varanda Restaurante

8. Com quem compartilhamos

Não vendemos, alugamos nem cedemos dados pessoais a terceiros para fins comerciais.

Compartilhamos dados apenas com prestadores de serviço estritamente necessários à operação, na medida do necessário:

  • Meta Platforms, Inc. — para o envio das mensagens pela WhatsApp Business Platform (API oficial)
  • Nomos Menu — sistema de caixa e gestão do restaurante, onde o cadastro e os pontos são gerados
  • Supabase — banco de dados onde armazenamos as informações do programa
  • Vercel — hospedagem do nosso painel de gestão

Podemos ainda compartilhar dados quando houver obrigação legal ou requisição de autoridade competente.

9. Por quanto tempo guardamos

Mantemos os dados de cadastro e o saldo de pontos enquanto o cliente estiver ativo no programa de fidelidade. O histórico de mensagens enviadas é mantido por até 24 meses, para fins de auditoria e comprovação de consentimento. Após a solicitação de exclusão, os dados são apagados nos prazos legais aplicáveis.

10. Seus direitos

Conforme a LGPD, o cliente pode, a qualquer momento e sem custo:

  • Confirmar se tratamos seus dados e acessar esses dados
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar a anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade com a lei
  • Revogar o consentimento e solicitar a exclusão dos dados tratados com base nele
  • Solicitar a portabilidade dos dados
  • Obter informação sobre com quem compartilhamos seus dados

Para exercer qualquer desses direitos, use os contatos abaixo. Responderemos no prazo legal.

11. Segurança

Adotamos medidas técnicas e administrativas para proteger os dados, incluindo: banco de dados com controle de acesso por linha (Row Level Security), credenciais de acesso mantidas exclusivamente no servidor (nunca expostas no navegador do usuário), acesso restrito à equipe responsável e uso exclusivo da API oficial da Meta para envio de mensagens.

12. Menores de idade

O programa de fidelidade é destinado a maiores de 18 anos. Não coletamos intencionalmente dados de crianças ou adolescentes. Caso identifiquemos um cadastro nessa condição, os dados serão excluídos.

13. Alterações nesta política

Podemos atualizar esta política. A data da última atualização estará sempre indicada no topo desta página. Alterações relevantes serão comunicadas pelos nossos canais.
